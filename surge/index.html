CodeMemory

The coding assistant that remembers the codebase. Ask a question — recall shows what the project remembers, with scores and sources. Nothing is invented: if no memory matches, it says so.

Built for ContextCon: Remember Everything (YugabyteDB × HackerEarth). Memories live in a Meko datapack — one shared context layer for every agent and session. Public repo

3 · Add a memory — with the hygiene gate

Memories you add are stored in your browser only (localStorage) for this demo. The hygiene gate refuses credential-like text at the write boundary — secrets never land in shared memory. Try it: the button above attempts api_key = "sk_live_4f8a2c...".

4 · All memories — promote & trace

Private by default; Promote moves a memory into shared team knowledge (one-way, like Meko — there is no un-promote). Trace shows everything the project remembers about that memory's file.

This static demo runs the same memory model locally in your browser (same ranking, same hygiene rules, same promote semantics). The live Meko mirror runs on the Node server — set MEKO_API_KEY + MEKO_DATAPACK_ID and run npm start (see the repo README). Every local write is mirrored fire-and-forget; a cloud failure never blocks the local write.

DEMO build — memories here come from the bundled demo repo (clearly labelled DEMO) or from what you type. The production store is a Meko datapack. Nothing in the demo is presented as a real project. Recall never invents an answer.
